# LETTERHUB

Sistem Administrasi & Otomatisasi Dokumen Berita Acara Serah Terima Pekerjaan (BAST) PJLP — **BPPP Ambon**.

## Fitur Utama
- **Standar Kop Resmi (`KOP BP3 2024.pdf`)**: Presisi ukuran huruf, warna, garis ganda, dan logo KKP proporsional 1:1.
- **Format Dokumen Standar Word (`Tahoma 12pt Justify`)**: Rata kanan-kiri penuh, inden kiri `0.05 cm`, spasi sebelum `7.8 pt`, terkunci **1 Halaman A4 (`210mm × 297mm`)** saat dicetak per pegawai.
- **Input Tanggal Global 1 Kali**: Pilih tanggal kalender 1 kali dan otomatis berlaku untuk seluruh dokumen pegawai.
- **Manajemen Data Pegawai, SPK & TTD**: Kelola biodata pegawai PJLP (Pihak Kedua) dan PPK (Pihak Pertama) lengkap dengan konversi angka *Terbilang* otomatis serta tanda tangan opsional.
- **Ekspor 1 per 1**: Cetak langsung ke PDF 1 halaman A4 atau unduh dokumen Microsoft Word (`.doc`).
